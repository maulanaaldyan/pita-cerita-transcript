Cara Meng-Online-kan 24 Jam di Vercel / Render (Gratis):
  1. Buka github.com → klik New Repository → beri nama pita-cerita-transcript.
  2. Klik uploading an existing file → masukkan ke-4 file di atas (index.html, app.py, requirements.txt, vercel.json) → klik Commit changes.
  3. Buka render.com atau vercel.com (login dengan akun GitHub) → pilih repository pita-cerita-transcript → klik Deploy. Link web kamu langsung aktif 24 jam dan bebas diakses dari rumah!
